# Naval 英语听力

这是一个给 iPhone 使用的 30 天游学式英语听力 App。第一版全部围绕 Naval Ravikant 常见思想主题，内容为原创听力课程，不直接搬运视频原文。

## 学习路线

每天 10-15 分钟：

1. 先听英文原文，抓大意。
2. 保存高价值语块，不孤立背单词。
3. 逐句慢速/正常朗读，听节奏、重音和连读。
4. 用中文复述，把“听见”变成“理解”。
5. 把重要表达存入语块本，后续复习。

## 当前功能

- 30 天 Naval 专项课程
- 慢速/正常英文朗读
- 逐句听力训练
- 高价值语块本
- 简单复习
- 粘贴英文视频字幕生成学习卡
- 一键复制豆包提示词
- 离线缓存能力

## 豆包配合方式

看到喜欢的英文视频时：

1. 复制英文字幕或视频文字。
2. 打开本 App 的“粘贴”。
3. 粘贴材料，点“复制给豆包”。
4. 到豆包里粘贴，让豆包生成更完整的听力训练课。
5. 回到本 App 保存最值得反复听的语块。
