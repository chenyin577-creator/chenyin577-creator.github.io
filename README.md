# Naval 英语听力

这是一个给 iPhone 使用的 30 天游学式英语听力 App。第一版全部围绕 Naval Ravikant 常见思想主题，内容为原创听力课程，不直接搬运视频原文。

## 学习路线

每天 10-15 分钟：

1. 盲听优先：先不看文字，只听声音，训练大脑直接处理英语声音信号。
2. 精听对照：第二步才显示英文字幕，用英文验证自己听到了什么。
3. 同步理解：逐句训练“听到就懂”，尽量跳过中文翻译。
4. 口语复刻：按住按钮跟读模仿，复刻节奏、重音、连读和弱读。
5. 最后复盘：完成理解后再看中文主旨，保存重要语块，后续复习。

## 当前功能

- 30 天 Naval 专项课程
- 盲听优先、精听对照、同步理解、口语复刻四步训练
- 慢速/正常英文朗读
- 逐句听力训练
- 高价值语块本
- 简单复习
- 粘贴视频链接，复制给豆包或 Codex 生成听力资料
- 粘贴英文视频字幕生成学习卡
- 一键复制豆包提示词
- 离线缓存能力

## 豆包配合方式

看到喜欢的英文视频时：

1. 打开本 App 的“粘贴”。
2. 粘贴视频链接，点“复制给豆包”或“复制给 Codex”。
3. 到豆包或 Codex 里粘贴，让它根据视频生成完整的听力训练课。
4. 如果视频没有公开字幕，再复制英文字幕或视频文字，粘贴到 App 里生成学习卡。
5. 回到本 App 保存最值得反复听的语块。
